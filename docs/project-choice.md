## Selected Project

Based on the evaluation above, I selected:

# Personal Expense Tracker

This project achieved the highest score because it is practical, can be demonstrated completely offline, does not require paid APIs, and has a simple data model that can be implemented within the available development timeline.

The project also provides a good opportunity to design meaningful MCP tools that allow users to manage and analyze their expenses through natural language interactions.

---

## Project Statement

**I am building a Personal Expense Tracker for students so that they can record, organize, and analyze their daily expenses easily through MCP tools.**

---

## Project Overview

The Personal Expense Tracker will provide an MCP server that allows users to manage their expenses using custom tools.

The server will support operations such as:

- Adding new expenses.
- Listing existing expenses.
- Generating spending summaries.
- Analyzing expenses by category.

The project will use local data storage to ensure that it can be demonstrated offline without requiring external APIs.

---

## Planned MCP Tools

The initial planned tools are:

| Tool                 | Purpose |
|----------------------|---------|
| add_expense          | Add a new expense record |
| list_expenses        | Display saved expenses |
| expense_summary      | Generate spending summaries |
| delete_expense       | Remove an existing expense |
| category_analysis    | Analyze spending by category |
